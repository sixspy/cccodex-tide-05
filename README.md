# 潮位报文归集台

港务水文组收到各潮位站的定长报文。归集员把一批报文贴进来，系统按站码和时刻解析、去重，能落库的写入归集表，列数不对、站码坏了或时刻已经存在的行单独列出。

## 技术栈

| 层 | 选型 |
|----|------|
| 接口 | Python FastAPI |
| 页面 | Vue 3，无组件库 |
| 数据库 | PostgreSQL 16 |

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3211 |
| 接口 | http://localhost:8211 |
| PostgreSQL | localhost:54411（库名 `tidetelegram`） |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| admin | 123456 | 归集员，可提交报文。登录页已填好 |
| archive | arch123456 | 档案员，只能查看 |

## 启动

```bash
cd projects/01-tide-telegram-intake
docker compose up --build
```

健康检查：`GET http://localhost:8211/api/health`

## 种子数据

| 批次 | 结果 |
|------|------|
| 吴淞口 11-12 早班 | 三行都已归集 |
| 外高桥 11-12 错报 | 一行新站落库，一行时刻重复，一行站码不合法 |

报文每行四段，用竖线分开：站码、十二位时间、潮位厘米、质量旗。质量旗 A 是实测，M 是插补，B 是可疑。
